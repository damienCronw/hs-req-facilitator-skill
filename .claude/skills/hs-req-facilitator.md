## ✨ 核心功能
这是一个**智能需求完善助手**，专门帮你：
- 📋 **自动分析**项目中的需求文档和用户故事
- 🔍 **识别问题**：模糊、不完整、缺少验收标准的地方
- 💬 **智能提问**：通过互动帮你澄清每个问题
- 📝 **完善文档**：自动更新需求文档，添加澄清结果
- 📊 **生成报告**：提供详细分析报告和改进建议

## 💡 描述
这是一个需求引导技能包，专门帮助完善用户故事和需求文档。通过智能分析项目中的文档和代码，识别用户故事和需求中存在的模糊、不完整或不明确的部分，然后通过AskUserQuestion工具与用户互动，收集必要信息来完善这些需求。

## 工作流程

### 第一阶段：项目扫描与需求提取
1. **扫描项目文档** - 自动扫描项目中的.md、.txt等文档文件
2. **识别用户故事** - 检测As a..., I want...格式的故事或编号用户故事
3. **提取需求** - 从需求文档中提取功能性和非功能性需求
4. **结构化存储** - 将提取的内容结构化存储

### 第二阶段：智能分析与问题识别
1. **完整性检查** - 检查每个用户故事是否包含：
   - 清晰的角色描述（As a...）
   - 具体的功能描述（I want...）
   - 业务价值说明（So that...）
   - 验收标准
   - 工作量估算

2. **不确定性检测** - 识别模糊表达，如：
   - "可能"、"也许"、"不确定"等词汇
   - TODO/TBD标记
   - 缺少具体细节的描述

3. **一致性验证** - 检查多个需求/故事之间是否存在矛盾或冲突

### 第三阶段：问题分类与优先级排序
1. **问题分类** - 将发现的问题分为：
   - **缺失信息**：缺少验收标准、业务价值、工作量估算等
   - **不确定性**：描述模糊、表达不明确的地方
   - **不完整性**：结构不完整的用户故事或需求
   - **歧义性**：容易产生多种理解的地方
   - **不一致性**：相互矛盾的需求

2. **严重程度评估** - 评估每个问题的严重程度：
   - **高优先级**：影响需求理解的关键问题
   - **中优先级**：重要但不紧急的改进点
   - **低优先级**：优化建议

### 第四阶段：交互澄清
1. **准备澄清问题** - 为每个问题准备具体的澄清问题
2. **通过AskUserQuestion工具询问用户** - 系统性地询问用户收集必要信息
3. **记录答案** - 将用户的回答存储并应用到对应的需求/故事中
4. **迭代完善** - 根据用户回答继续深入询问

### 第五阶段：文档更新与报告生成
1. **更新原始文档** - 在原有需求文档基础上添加澄清结果
2. **生成增强版文档** - 创建包含完整信息的新版本文档
3. **生成分析报告** - 输出详细的分析结果和改进建议
4. **提供下一步行动建议** - 给出具体的后续工作建议

## 关键规则

1. **不跳过任何问题** - 对每个发现的问题都会询问用户，不会自行假设
2. **尊重原始文档** - 在原有文档基础上更新，不会完全重写
3. **按优先级处理** - 先处理高优先级问题，再处理低优先级问题
4. **自动备份** - 更新文档前会自动备份原版本
5. **生成详细报告** - 每次分析都会生成包含统计、问题和建议的详细报告
6. **支持多种格式** - 支持markdown、txt、rst等常见文档格式
7. **排除非必要文件** - 自动排除node_modules、.git等目录
8. **记录澄清过程** - 完整记录所有问答过程，方便追溯

## 输出文档
技能包会生成以下文档：
1. **增强型需求文档** - 在原始文档基础上添加分析结果和完善信息
2. **需求澄清报告** - 详细的问答过程和改进建议
3. **问题清单** - 按优先级排序的所有发现的问题
4. **下一步行动建议** - 具体的后续工作指导

## 限制说明
- 主要支持Markdown格式的文档
- 需要文档使用中文或英文编写
- 暂不支持图片、图表中的需求信息
- 无法理解复杂的业务逻辑，需要用户配合澄清

## 常见问题

**问：分析完成后文档会被修改吗？**
答：是的，技能包会在原有文档末尾添加分析结果和澄清信息，不会覆盖原内容。

**问：如果项目中没有需求文档怎么办？**
答：技能包会创建一个新的增强型需求文档，包含所有分析结果。

**问：可以指定只分析特定文档吗？**
答：可以，技能包支持通过配置文件指定包含和排除的文件模式。

**问：一次可以处理多少个问题？**
答：默认最多处理10个问题，可通过配置调整。
